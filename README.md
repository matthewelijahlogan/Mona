# MONA

MONA stands for **Model Of Natural Advancement**.

This repository contains the MONA mobile app, the supporting FastAPI backend, and the public privacy policy used for Google Play submission.

## Maintained by

- **Touch Of Davinci Studios**
- Author: **Matthew Elijah Logan**

## Key Paths

- `mobile/` - Expo/React Native Android app
- `main.py` - FastAPI entrypoint for the hosted backend
- `render.yaml` - Render deployment blueprint
- `docs/privacy-policy.html` - public privacy policy page for GitHub Pages / Google Play
