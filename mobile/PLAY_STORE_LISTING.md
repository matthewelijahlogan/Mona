## Full Description

`MONA, the Model Of Natural Advancement, is a standalone mobile research app built by Touch Of Davinci Studios.

Explore cancer-focused simulation tools directly on your device. MONA bundles its core research stack into the phone so you can browse elements, run simulations, review top synthetic candidates, and score recipes without needing a live server.

Core features include:

- Quick Predict for fast on-device recipe scoring
- bundled periodic-table exploration with cancer overlays
- standalone simulation tools for comparing element behavior
- synthetic candidate rankings and recent run history
- optional Turbo backend support for hosted prediction and leaderboard features

MONA is designed to stay useful even when no backend is connected. When a compatible hosted backend is available, the app can also reach connected prediction and leaderboard endpoints.

MONA stands for Model Of Natural Advancement.`
